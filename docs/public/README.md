# 분석 시스템과 알고리즘

이 문서는 플랫폼이 가격 구조를 해석하고, 종목을 비교하고, 모의매매의 진입·청산을 판단하는 과정을 설명합니다. 개인 학습 자료에서 검토한 개념을 실행 가능한 조건으로 정리하되, 설명의 기준은 현재 구현된 코드입니다. 원문·사본·스크린샷·개인 기록을 재배포하지 않으며, 아래 글은 코드와 계산식을 바탕으로 새로 작성했습니다.

문서 기준: 2026-10-06. 차트 계산 버전은 `financial-study-v1`, 선택형 모의매매 정책은 `chart-confirmed-v1`입니다. 수치와 임계값은 구현 기본값이며 검증된 승률이나 최적 매개변수라는 의미가 없습니다.

## 전체 흐름

```text
시세·OHLCV → 지표와 전략 신호 → 종목 비교 점수
                        ↓
완성 일봉 → 확인 피벗 → 돌파 → 리테스트 → 후속 종가 확인
                        ↓
추세·거래량·신호 유효성 → 현재가·순손익비·위험 한도
                        ↓
대상 모의계좌에 체결·계획 저장 → 가격 감시 → 청산·복기
```

차트 화면은 해석을 돕고, 오토파일럿은 선택한 정책의 명시적인 조건을 검사합니다. 점수가 높은 종목도 차트 확인 조건이나 위험 한도를 충족하지 못하면 선택형 차트 정책으로 진입하지 않습니다. 사람이 그린 선이나 입력한 IV 가정은 자동매매 입력으로 저장되지 않습니다.

## 읽는 순서

1. [분석 파이프라인과 종목 점수](ANALYSIS_PIPELINE.md): 데이터에서 전략 신호와 종목 순위가 만들어지는 과정.
2. [차트 해석을 계산으로 바꾸는 방법](CHART_METHODS.md): 피벗, 가격 구간, 리테스트, 다이버전스, 거래량과 수동 계산.
3. [차트 확인 모의매매 정책](TRADING_POLICY.md): 확인 시점, 목표·손절, 진입 제한, 신호 중복 방지와 청산.
4. [위험 수량과 검증 방법](RISK_AND_BACKTEST.md): 비용·환율·총 위험, 백테스트와 매매 저널의 계산 범위.
5. [데이터와 구현 한계](DATA_AND_LIMITS.md): 제공 데이터, 추정치, 미연결 기능과 공개 배포 경계.

## 실행 범위

웹 모의투자와 오토파일럿은 로컬 모의 원장을 사용합니다. 별도의 저수준 브로커 주문 클라이언트는 존재하지만, 이 문서의 차트 확인 정책은 실거래 체결 동기화나 실주문 운용이 검증된 정책이 아닙니다. 기존 퀀트 지지 구간 정책이 기본이고, 차트 확인 정책은 사용자가 선택하는 실험 기능입니다.

단위 테스트와 화면·패키지 검사는 규칙과 배포 동작을 확인합니다. 장기 투자 성과, 실제 체결 품질 또는 자료의 주장까지 검증한 결과로 해석할 수 없습니다.
