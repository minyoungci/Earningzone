# 차트 확인 모의매매 정책

`chart-confirmed-v1`은 해석을 시간 순서가 있는 진입 조건으로 바꾼 실험 정책입니다. UI와 API의 선택값은 `chart_confirmed`입니다. 기본 `legacy`와 별도로 선택하며, `tossbot/chart_execution.py`는 조건·수량을 계산하고 `tossbot/autopilot.py`가 로컬 모의 원장을 갱신합니다. 정책은 주식 롱·일봉에 한정됩니다.

## 1. 입력 품질

완성 일봉이 최소 60개 필요합니다. 최신 완성 봉이 7일보다 오래되거나, 잘못된 OHLCV 또는 중복이 있으면 신규 신호를 막습니다. 현재 UTC 날짜의 일봉은 제거합니다. 이 검사와 일반 지표·차트 화면의 정제 방식은 구분됩니다. 화면에서 정제해 표시할 수 있는 데이터도 실행 정책은 거부할 수 있습니다.

## 2. 확인 시점

꼬리 기준 좌우 3봉으로 확인된 최근 고점 피벗 최대 12개를 평가합니다. 각 피벗의 확인 시점 ATR14×0.25 구간에 대해 [돌파→리테스트→후속 종가 확인](CHART_METHODS.md)을 요구합니다.

확인 봉까지 계산한 `종가 > EMA20 > EMA50`과 확인 봉의 `RVOL20 ≥ 1.2`를 함께 검사합니다. 가장 최근 확인 이후 추가 완성 봉이 2개를 넘거나 확인 날짜의 UTC 자정부터 4일을 넘으면 신호 후보가 만료합니다. 실제 주문 직전 수량 계산에서는 4일 만료 시각에 도달한 신호도 거부합니다. 이 값들은 코드에 정한 기본값이며 최적화된 성공률 기준은 아닙니다.

현재 차트가 하락 구조 또는 구조 이탈이거나 무효화되지 않은 약세 다이버전스가 있으면 새 진입을 막습니다. 하락 구조·구조 이탈은 청산 신호도 내지만, 약세 다이버전스만으로 자동 청산하지 않습니다.

## 3. 목표·손절·진입 범위

확인 시점까지 알려진 피벗만 사용합니다. 돌파 고점보다 앞선 최근 저점과의 높이를 돌파 고점 위로 투영해 목표를 계산합니다. 확인 종가 위의 이미 알려진 고점이 있으면 가장 가까운 고점으로 목표를 제한합니다. 패턴 이름을 자동 인식한 것이 아니라 확인된 스윙 높이의 투영입니다.

```text
목표 후보 = 돌파 피벗 고점 + (돌파 피벗 고점 - 앞선 확인 저점)
손절 = min(리테스트 봉 저가, 구간 하단) - 0.25 × ATR
진입 하단 = 구간 상단
진입 상단 = 확인 종가 + 0.5 × ATR
```

여기서 ATR은 돌파 피벗의 확인 시점 값입니다. 손절<확인 종가<목표여야 하고, 확인 후 다른 봉의 고가가 목표 또는 저가가 손절에 이미 도달한 셋업은 진입 후보에서 제외합니다. 여러 셋업이 남으면 가장 최근 확인 봉, 그 다음 최근 피벗 확인을 선택합니다.

이후 현재가가 진입 범위 밖이거나 목표·손절을 이미 통과했다면 매수하지 않습니다. 목표와 손절을 현재 시세에 맞춰 계속 유리하게 재계산하는 대신 확인 시점 계획을 사용합니다.

## 4. 계좌·위험·시장 조건

시작할 때 대상 모의계좌를 고정합니다. 화면에서 활성 계좌를 바꿔도 실행 대상이 바뀌지 않습니다. 이미 보유한 종목, 보유 슬롯 초과, 사용한 확인 신호는 다시 매수하지 않습니다. 동일 계좌에서 `정책 버전:종목:확인 날짜`를 신호 ID로 사용합니다.

[순손익비와 위험 수량](RISK_AND_BACKTEST.md)은 주문 직전 현재가, 현금, 평가 자산, 예산과 환율로 다시 계산합니다. 기존 보유 종목의 시세나 필요한 환율을 확인할 수 없으면 평가액과 총 위험을 확정할 수 없으므로 신규 진입을 보류합니다.

레짐 가드가 켜져 있으면 VIX·VVIX·SPX·TLT·UUP·HYG 여섯 입력이 모두 유효하고 결과가 stale/degraded가 아닌지 검사합니다. 누락은 평시로 간주하지 않습니다. FRACTURE에서는 예산을 절반으로 줄이고 TRIGGER 또는 알 수 없는 단계에서는 신규 진입을 막습니다. 기본 정책의 FRACTURE 점수 문턱 상향은 기본 정책에 적용되며 차트 정책의 별도 최소 점수 조건은 아닙니다. 가드를 끄면 이 시장 조건 검사는 적용되지 않습니다.

## 5. 저장과 청산

매수 체결과 실행 계획·신호 사용 기록은 모의 원장의 같은 저장 작업에 포함됩니다. 계좌별 사용 신호 기록은 일반 매매 표시 이력과 별도로 유지하며 오래된 기록은 정리합니다. 목표·손절은 포지션에 저장되어 앱 재시작 뒤 다시 읽을 수 있습니다. 로그를 비워도 보유 계획은 유지됩니다.

폴링마다 유효한 현재가가 목표 이상 또는 손절 이하인지 검사하고, 분석 대상에 포함된 보유 종목의 구조 청산 신호도 처리합니다. 신규 진입을 시장 가드가 막아도 청산은 계속합니다. 시세가 없으면 임의 가격으로 청산하지 않습니다.

이는 거래소에 상주하는 스톱 주문이 아닙니다. 폴링 지연·가격 갭·앱 종료 중에는 손절선 체결이 보장되지 않습니다. 모의 체결 가격은 확인한 현재가이고 실제 주문 체결·유동성·부분 체결을 재현하지 않습니다.
