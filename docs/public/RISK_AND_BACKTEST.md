# 위험 수량과 검증 방법

진입 여부와 진입 규모는 별도 판단입니다. 차트가 확인되어도 현재가에서 예상 손실 대비 이익이 충분하지 않거나, 계좌 위험·현금·예산이 부족하면 수량은 0입니다. 아래 자동 정책 식은 `tossbot/chart_execution.py`의 `entry_size`와 모의 원장의 비용 모델을 설명합니다.

## 비용과 환율

P=현재 진입가, S=손절, T=목표, f=편도 수수료, t=매도 세금, x=종목 통화 1단위당 원화 환율로 둡니다. 원화 종목의 x는 1입니다.

```text
1주 매수 비용 C = P × (1+f) × x
1주 예상 손실 L = C - S × (1-f-t) × x
1주 예상 이익 G = T × (1-f-t) × x - C
순손익비 = G / L
```

현재 모의 비용은 f=0.00015(0.015%), t=0.0018(0.18%)이며 한국·미국 종목 모두에 같은 값이 적용됩니다. 시장별 실제 과세·수수료를 정확히 모델링한 값이 아닙니다. 자동 정책에는 별도의 슬리피지 입력이 없으며 실제 비용 검증이 필요합니다. 수동 위험 도구는 수수료·세금·편도 슬리피지를 직접 입력할 수 있고 기본 0은 사용자 가정입니다.

## 수량과 총 위험

평가 자산 E, 설정 위험 비율 r%, 최대 보유 수 m, 기존 포지션의 현재가 기준 예상 손절 손실 O라면 다음을 계산합니다. 기존 위험은 현재가와 저장 손절의 비용 차감 후 회수액 차이의 양수 부분을 수량·환율로 원화 환산해 합산합니다. 기존 포지션의 현재가에는 새 매수 수수료를 추가하지 않습니다. 저장 계획이 없는 포지션은 메모리 계획 또는 평균 매수가의 92% 손절을 대체 기준으로 사용합니다.

```text
거래별 위험 한도 A = E × r / 100
이번 거래 위험 예산 B = min(A, max(0, A×m-O))
수량 = floor(min(가용 현금/C, 매수 예산/C, B/L))
```

순손익비가 설정 하한보다 작으면 진입을 거부합니다. 기본 위험 비율은 0.5%, 최소 순손익비는 1.5이며 사용자가 설정할 수 있습니다. 이 값들은 제품 기본값이고 특정 계좌에 적합하다는 추천이 아닙니다. 1주도 살 수 없으면 억지로 1주로 올리지 않습니다.

가상의 P=100, S=95, T=110, x=1이면 C=100.015, L=5.20025, G=9.7705, 순손익비는 약 1.88입니다. 위험 예산이 50이고 현금·매수 예산이 충분하면 9주, 초기 예상 손실은 약 46.80입니다. 가격 차이만 사용하면 10주이지만 비용을 포함하면 9주입니다. 이 예시는 계산 설명이며 실제 시세나 개인 거래 기록이 아닙니다.

이 위험 한도는 손절 가격에 회수할 수 있다는 모델 가정입니다. 갭과 슬리피지, 종목 간 상관관계, 거래 중 환율 변화까지 반영한 최악 손실 한도는 아닙니다.

## 현재 백테스트의 범위

`tossbot/backtest.py`는 최대 200봉 중 60봉을 준비 구간으로 사용합니다. 봉 i의 전략 판단에는 i 이전 데이터만 사용하고, BUY/SELL 신호 체결은 다음 봉의 시가로 계산합니다. 매수는 수수료를 포함한 전액 진입이며 소수 수량을 허용합니다. 보유 중 손절 비율 또는 저장 지지선 이탈은 그 봉의 종가를 기준으로 확인·체결합니다. 손절선의 장중 터치 가격 체결로 해석하면 안 됩니다.

전략군 비교는 같은 특징·신호 스트림을 공유하면서 각 범주의 포지션을 독립적으로 계산합니다. 부분 전략군은 참여 전략 수 비율로 집계 문턱을 줄이고 절대값 0.8을 바닥으로 사용합니다. 총수익률, 승률, 최대 낙폭, 샤프, 이익합/손실합, 보유 노출을 표시합니다. 손실 합이 0이면 손익비를 무한대로 표시하지 않고 누락값으로 반환합니다.

**이 백테스트는 기존 집계 전략의 엔진입니다.** 차트 확인 정책의 EMA·RVOL·신호 만료·위험 수량·포트폴리오 가드를 같은 체결 모델로 재생하는 전용 성능 검증은 구현되어 있지 않습니다. 기존 화면의 백테스트 성적을 새 정책의 성적으로 제시할 수 없습니다.

## 매매 저널과 검증 구분

`tossbot/journal.py`는 모의 원장의 SELL 체결을 거래 1건으로 셉니다. 부분 매도도 각각 집계하고 본전은 승·패에 넣지 않습니다. 실현손익은 비용 차감 후 원화 값입니다. 현재 `expectancyR`은 실현손익/추정 투입원금의 평균이며, 최초 손절 위험으로 나눈 표준 R-multiple이 아닙니다. 과거 USD 거래의 환율 추정이 불가능하면 그 평균 계산에서 제외합니다.

현재 검사는 확인 전에 신호가 나오지 않는지, 순서·무효화·비용·위험 수량·신호 중복 방지가 지켜지는지 확인합니다. 수익성 평가에는 더 긴 이력, 시장별 비용·거래 달력, 실제 체결 가정, 표본 밖 기간과 전체 포트폴리오 재생이 별도로 필요합니다. 검증된 수익률이나 승률은 현재 공개 문서에서 주장하지 않습니다.
