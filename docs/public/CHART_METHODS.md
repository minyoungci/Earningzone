# 차트 해석을 계산으로 바꾸는 방법

차트를 해석하는 표현은 관측 조건, 확인 시점, 무효 조건으로 나누어 구현합니다. 이 문서는 `tossbot/chart_study.py`와 `web/src/lib/studyMath.js`의 동작을 설명합니다. 자동 계산은 관측 데이터에서 나오고, 수동 도구는 사용자의 입력 가정에서 나옵니다.

## 완성 봉과 가격 구조

가격은 유한한 양수, 거래량은 유한한 0 이상의 값이어야 하고 OHLC의 고저 관계를 검사합니다. 동일 시각의 봉은 마지막 입력을 사용하면서 중복 수를 기록합니다. 일봉은 이전 UTC 날짜, 분봉은 시간대가 있는 시작 시각+1분이 지난 봉만 사용합니다. 제공자의 완성 표시가 없어서 적용한 추정 규칙이며 거래소 마감 달력을 반영하지 않습니다.

피벗은 좌우 N봉보다 엄격히 높은 고점 또는 낮은 저점입니다. 같은 높이의 평평한 구간은 피벗으로 선택되지 않습니다. 꼬리 기준은 high/low, 몸통 기준은 max(open, close)/min(open, close)를 비교합니다. 화면은 N=2~10, 자동 정책은 N=3입니다.

피벗 발생일과 `confirmedAt`은 다릅니다. N=3이면 오른쪽 3봉이 완성되어야 피벗을 알 수 있습니다. 이미 알려진 피벗을 과거 발생일로 표시하더라도 매매 판단에는 확인 이후만 사용할 수 있습니다. 연속 고점·저점의 HH/HL은 상승, LH/LL은 하락, 나머지는 혼합입니다. 상승 구조의 최근 저점을 종가로 하향 이탈하거나 하락 구조의 최근 고점을 종가로 상향 이탈하면 `broken`으로 표시합니다.

## 가격 구간과 리테스트

피벗이 확인된 시점까지 계산한 ATR14의 0.25배를 반폭으로 고정합니다. 이후 변동성이 바뀌어도 해당 구간의 과거 폭을 다시 계산하지 않습니다.

```text
구간 하단 = 확인 피벗 가격 - 0.25 × 확인 시점 ATR14
구간 상단 = 확인 피벗 가격 + 0.25 × 확인 시점 ATR14
watching → breakout → retest → confirmed
```

상방 돌파에서는 이전 종가가 상단 이하이고 새 종가가 상단 위이면 `breakout`입니다. 다른 후속 봉이 구간과 겹치고 종가를 상단 위에 유지하면 `retest`입니다. 다시 다른 봉이 상단 위에서 리테스트 봉의 고점을 종가로 넘어야 `confirmed`가 됩니다. 하방은 대칭 조건을 적용합니다. 한 봉을 돌파·리테스트·확인에 동시에 사용하지 않습니다.

돌파 이후 확인 전 대기가 20봉을 넘으면 만료하고, 진행 중 반대편 구간을 종가로 이탈하면 무효화합니다. 새로운 교차 돌파가 생기면 만료·무효 구간에서도 다시 과정을 시작할 수 있습니다. 구간 접촉 횟수는 연속 접촉을 하나로 세며 지지의 성공 확률로 환산하지 않습니다.

## RSI·MACD 다이버전스

동일한 두 확인 저점에서 가격은 낮아지고 지표는 높아지면 강세 후보입니다. 확인 고점에서 가격은 높아지고 지표는 낮아지면 약세 후보입니다. RSI14와 MACD 12/26/9의 line을 각각 비교하며 히스토그램과 혼용하지 않습니다.

후보가 알려지는 시점은 두 번째 피벗의 확인 시점입니다. 그 뒤 강세 후보의 두 번째 저점 아래 또는 약세 후보의 두 번째 고점 위로 종가가 넘어가면 무효 시각을 기록합니다. 이후 반등이 생겨도 해당 두 피벗에서 발생한 무효 기록은 지우지 않습니다. 후보 자체는 가격 반전 확인이나 단독 매수 명령이 아닙니다.

## 거래량·갭·변동성

| 관측값 | 계산 | 해석 범위 |
|---|---|---|
| RVOL20 | 현재 봉 거래량 / 직전 20봉 평균 | 현재 봉을 분모에서 제외한 활동성 |
| 방향 거래량 | 최근 20봉 Σ(거래량×종가 변화의 부호) / Σ거래량 | -1~1의 가격 방향 대리값 |
| 큰 음봉과 거래량 | 해당 봉 RVOL≥1.5, 음봉 몸통≥그 직전 ATR | 최근 20봉에서 조건을 만족한 날짜 |
| 갭/ATR | (현재 시가-이전 종가)/직전 ATR | 변동성 대비 갭 크기 |
| 종가 위치 | (종가-저가)/(고가-저가) | 당일 범위 안의 마감 위치 |
| 실현 변동성 | 최근 20개 로그 수익률의 표본 표준편차 | 일봉은 √252를 곱한 연율, 분봉은 봉당 값 |

방향 거래량은 실제 매수·매도 체결 델타가 아니고 기관 수급을 식별하지 않습니다. 분봉 RVOL은 동일한 장중 시각의 과거 평균이 아닙니다. `earningsVerified=false`이므로 갭이 실적 발표 때문에 생겼다고 확정하지 않습니다. 거래량 0으로 분모를 만들 수 없거나 이력이 부족하면 누락값을 표시합니다.

## 수동 시나리오

피보나치 상승 스윙의 되돌림은 `끝 가격-r×(끝 가격-시작 가격)`입니다. 측정 목표는 사용자가 지정한 높이 `상단-하단`을 돌파 가격에 더하거나 이탈 가격에서 뺍니다. 예를 들어 가상의 상단 120, 하단 100, 돌파 122이면 상방 측정 목표는 142입니다. 실제 종목의 패턴 인식이나 목표 달성 검증 결과가 아닙니다.

예상 변동폭은 `S×(IV%/100)×√(남은 기간/연간 기준)`이고 범위는 S±변동폭입니다. 연간 기준은 달력일 365 또는 거래일 252이며 기간도 같은 단위여야 합니다. 만기별 실시간 IV를 조회하지 않고 직접 입력합니다. 정규성 가정이나 옵션 가격 모델을 검증하지 않으므로 특정 확률, 구간 터치 확률 또는 만기 종가 확률로 표시할 수 없습니다.

수동 위험 수량은 [비용과 환율을 반영한 계산](RISK_AND_BACKTEST.md)으로 제공하지만 자동 정책에 저장되지 않습니다.
