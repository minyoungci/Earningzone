# 분석 파이프라인과 종목 점수

플랫폼은 관찰, 비교, 실행 판단을 순서대로 처리합니다. 먼저 OHLCV로 지표를 만들고 전략 신호를 집계합니다. 그 결과로 종목 비교 점수를 계산한 뒤, 선택형 차트 정책에서는 별도의 시간 순서와 위험 조건을 검사합니다. 여러 지표가 같은 가격 이력에서 계산되므로 전략 수가 많다는 사실만으로 독립적인 증거가 많아지는 것은 아닙니다.

## 1. 지표와 전략 신호

`tossbot/features.py`가 수익률, 이동평균, RSI, MACD, ATR, ADX, 거래량 비율과 지지·저항 등을 구성합니다. `tossbot/strategies/`는 일봉 94개 전략을 등록하고, 분봉 분석에는 분봉 전용 5개 전략을 추가합니다. 각 전략은 방향과 점수를 반환하고, `tossbot/analysis.py`가 범주별 가중합을 계산합니다.

```text
집계 점수 = Σ(전략 점수 × 해당 범주의 가중치)
```

| 범주 | 추세 | 모멘텀 | 변동성 | 평균회귀 | 돌파 | 구조 |
|---|---|---|---|---|---|---|
| 가중치 | 1.0 | 1.0 | 0.9 | 0.8 | 1.0 | 1.1 |

전체 집계가 2.5 이상이면 BUY, -2.5 이하이면 SELL, 사이면 HOLD입니다. 전략 실행 오류가 기록되면 집계 방향은 HOLD로 처리합니다. 이 분류는 규칙의 결과이며 주문 접수나 수익 확률을 의미하지 않습니다.

## 2. 종목 비교 점수

`tossbot/quant.py`의 `quant_score`는 다섯 요소를 0~1로 변환하고 다음 가중합을 0~100점으로 표시합니다.

| 요소 | 비중 | 계산 기준 |
|---|---|---|
| 모멘텀 | 30% | 20봉·60봉 수익률과 20봉 수익률/ATR%의 평균 |
| 추세 | 25% | ADX와 스윙 구조의 평균 |
| 전략 집계 | 20% | 집계 점수를 -5~5 구간에서 정규화 |
| 거래량 | 10% | 특징 엔진의 거래량 비율을 0.5~2.5 구간에서 정규화 |
| 타이밍 | 15% | RSI 구간 점수와 관측 고점 근접 감점 |

정규화는 `clip((값-하한)/(상한-하한), 0, 1)`입니다. 모멘텀의 세 구간은 각각 -10~20%, -20~40%, -3~5이고 ADX는 10~40입니다. 상승 구조는 1, 횡보는 0.5, 하락은 0으로 처리합니다. 일부 값이 없으면 알려진 값끼리 평균하고, 모두 없으면 0.5를 사용합니다. 중립 대체값은 계산을 위한 기본값이며 실제로 관측한 정보가 아닙니다.

RSI 30~60은 1, 60~70은 1에서 0.1로 선형 감소, 70 이상은 0.1, 30 미만과 누락은 0.5입니다. 관측 고점에서 -5% 이내이거나 고저 범위 위치가 95% 이상이면 타이밍 점수에서 0.4를 차감하고 0을 바닥으로 둡니다. `pos52`라는 내부 이름과 달리 최대 200봉 데이터의 관측 범위를 사용하므로 완전한 52주 통계로 단정하면 안 됩니다.

**80점은 80% 승률이 아닙니다.** 이 점수는 현재 관측 조건을 비교하는 휴리스틱입니다. 시장별 확률 보정이나 표본 밖 성능 검증은 구현되어 있지 않습니다.

## 3. 기본 정책과 차트 확인 정책

기본 `legacy` 정책은 집계 BUY, 지지 구간 안의 현재가, 최소 점수, 미보유와 보유 슬롯을 확인합니다. 매매 플랜의 진입 범위는 최근접 지지~지지×1.015, 손절은 지지×0.97, 목표는 최근접 저항입니다. 플랜의 표시 손익비는 구간 상단 기준의 가격 비율이며, 차트 확인 정책의 비용 포함 최소 손익비와 구분해야 합니다.

선택형 `chart_confirmed` 정책은 같은 분석에 사용한 캔들을 재사용해 [완성 일봉의 확인 과정](TRADING_POLICY.md)을 평가합니다. 스크리너는 적격 후보를 먼저 두고 퀀트 점수를 정렬에 사용합니다. 실제 진입은 현재가 범위, 비용 포함 순손익비, 위험 수량을 통과해야 하며 높은 퀀트 점수만으로 실행되지 않습니다. 선택한 유니버스에 속한 보유 종목은 순위 밖이어도 분석 대상으로 유지하지만, 유니버스 밖 종목의 구조 신호까지 자동 수집하는 것은 아닙니다.

## 4. 화면과 실행의 관계

차트 스터디는 일봉·1분봉, 피벗 폭과 꼬리·몸통 기준을 사용자가 바꾸며 살펴보는 분석 도구입니다. 선택형 자동 정책은 일봉, 꼬리 기준, 좌우 3봉으로 고정합니다. 화면에서 조건을 바꾸거나 수동 목표선을 그려도 실행 정책이 변경되지 않습니다.

분석 결과는 캐시에 저장하고 같은 조회를 공유합니다. 따라서 순위 화면의 점수와 이후 주문 평가의 현재가는 서로 다른 시점일 수 있습니다. 실행 단계에서 현재가와 신호 만료를 다시 검사하지만, 거래소 주문장과 실체결까지 재현하는 모델은 아닙니다.
